# TACZ 1.2.0-neoforge-mc1.21.1

内容同步至1.2.0-forge-mc1.20.1

## 额外调整和内容
- 新增 Minecraft 1.21.1 的 NeoForge 版本，运行环境改为 Java 21。
- 枪械、弹药、配件等物品数据适配数据组件，原自定义 NBT 数据存放于 `minecraft:custom_data`。
- 脚本 NBT 读写接口适配新版物品数据，保留原有调用方式。
- 枪包中的配方、战利品、进度及标签适配 1.21.1 数据格式。
- 枪包支持按 Minecraft 版本加载覆盖层，可在同一枪包中保留不同版本的适配资源。
- 默认枪包改为导出 1.20.1 通用主包与 1.21.1 覆盖层。
- 新增 `/tacz convert universal` 旧枪包转换工具，用于自动生成1.21.1的覆盖层，支持单包与批量检查、导出。
  - 转换后的枪包同时支持 1.20.1 和 1.21.1
  - 转换结果与报告另存至 `tacz-converted` 目录。
  - 支持通过自定义规则调整物品标签的转换映射。
- 光影兼容改为对接 Iris。
- 适配 Player Animator 2.x，保持旧版玩家动画的插值表现。
- 1.21.1 版暂不提供 KubeJS 专用兼容接口。

# TACZ 1.2.0-forge-mc1.20.1

## 新内容

### 枪械

- 突击步枪：AK-12、AK-74M、H.C.A.R.、MCX Spear LT、MK18、QR-24、URGI。
- 手枪与冲锋枪：TEC-9、MP7A1。
- 射手步枪：SCAR-MK20、温彻斯特 M1866。
- 狙击步枪：SVD、MRAD、HM50B。
- 霰弹枪与机枪：M1897「堑壕清扫者」、PKM。

### 配件

- 新增 APM4s、1P87 反射式瞄具。
- 新增 PSO-1、C79、Mark 4 ER/T、AMG 10、老式温彻斯特神射手瞄具。
- 新增 XM157 火控瞄具。
- 新增 REAP-IR、FMP13、脉冲星 XL50 热成像瞄具。
- 新增 Magpul AFG、TROY 斜角握把。
- 新增 NGAL 激光指示器。
- 新增圣焰 RC1 特种作战快拆消音器。
- 新增 CTR 重型枪托、PSG 神射手枪托。
- 新增手枪低／中／高增高座、导轨中／高增高座及 Unity 增高座。
- 新增战术、格斗、HK、AUG 原厂机瞄。
- 新增两种原厂护木片。
- 新增 M16A1 突击护木。
- 新增 M1897 原厂刺刀。
- 新增 M1866 原厂炮兵枪管。
- 新增枪托展开／拆除选项（内置配件）。
- 新增弹药改装配件「超压反冲弹」。

### 子弹

- 新增 .300 BLK 步枪弹。

### 方块

- 新增挂板与发光挂板，支持拼接、转角、双面陈列、染色和放置预览。
- 新增可拼接、锁定的枪械展示柜。
- 新增铁、金、钻石弹药库，支持大容量存储、升级、携带及弹药盒快速存取。

## 新特性

- 更新基于雪暴粒子（SnowStorm）枪口焰与枪烟效果，支持枪口配件调整效果表现。
- 现在开火时会短暂照亮第一人称下的手部模型。
- 添加了新的镜片镜片效果
  - 可配置的镜片边缘畸变、色散、染色与暗角效果。
  - 可选择夜视及白热、黑热、铁红热成像等特殊效果。
- 新增瞄具测距显示支持。
- 新增火控瞄具弹道落点预测。
- 新增瞄具弹量数显支持，UH-1 升级为智能数显瞄具。
- 改装界面支持切换内置的原厂配件，无需消耗实际配件。
- 改装界面支持选择增高座适配器。
- 新增卸弹操作，默认按键为 `Alt + R`，增加相关的脚本API。
- 新增可配置的开镜过渡选项，支持自定义开镜路径和 FOV 预设。
- 新增后坐力推进机制，可按站立、腾空、蹲伏与趴伏分别设置。
- M1866 支持腰射与瞄准使用不同的拉栓速度。
- 新增可配置的命中表面特效和近战粒子效果。
- 重新加入了枪声仇恨机制，开火会惊动附近中立生物并吸引敌对生物，除非安装了消音器。可在配置文件中关闭。
- 趴下不再要求手持枪械。
- 现在可以配置趴下的俯仰角度限制了。
- 可在枪械data中配置在收起后在背包中是否继续冷却（默认否），已适配 Minigun。
- 创造模式新增枪包筛选侧栏，可在枪包元数据中配置使用的图标。
- JEI 新增枪械配件、弹药适配查询。
- JEI 支持工作台配方转移，可跳转到工作台的对应配方。
- 新增 TaCZ 进度路线，涵盖制造、改装、收藏及射击挑战。
